# 手動確認手順（公開後）

公開・再デプロイのたびに、以下を人の目で確認する。

## PC（Chrome / Safari）

- [ ] 4 ゲーム（インベーダー・ブロック崩し・もぐらたたき・テトリス）をキーボードで開始〜ゲームオーバーまで遊べる
- [ ] テトリスでキー凡例が表示される
- [ ] パンくずのリンクに Tab で移動でき、Enter で開ける
- [ ] 解説までスクロールした状態では ↑↓・Space でページがスクロールする

## スマホ実機（iOS Safari / Android Chrome）

- [ ] 4 ゲームをタッチで遊べる
- [ ] ゲーム中に画面がスクロールしない
- [ ] ゲームの下の解説（guide）は指でスクロールできる
- [ ] 操作ボタンのすぐ下・横に広告が表示されない
- [ ] アンカー広告が表示されない

## ブラウザの挙動

- [ ] 「戻る」「進む」でゲームページに戻っても動く
- [ ] プライベートブラウズでも遊べ、そのセッション内で BEST が更新される

## GA4 / GTM

- [ ] GA4 リアルタイムに `page_view` が届く
- [ ] GA4 リアルタイムに `game_start`（`game_id` 付き）が届く
- [ ] GA4 リアルタイムに `game_over`（`game_id`・`score` 付き）が届く
- [ ] GTM プレビュー（Tag Assistant）で、Google タグが同意の初期値の後に発火する

## Search Console

- [ ] 所有権が確認済み
- [ ] サイトマップの状態が「成功」
- [ ] URL 検査で `/games/tetris/` が「URL は Google に登録できます」と表示される

## AdSense

- [ ] 広告枠が表示される（承認直後は空白のことがある）
- [ ] `https://browser-games.creator-world.net/ads.txt` の内容が正しい
