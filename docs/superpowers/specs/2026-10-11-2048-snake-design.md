# 2048・スネーク 設計書

- 日付: 2026-10-11
- 対象: `kh55/creator-world-games`（https://browser-games.creator-world.net）
- 追加先: `src/engine/swipe.ts`、`src/games/2048/`、`src/games/snake/`、`tests/e2e/games/{2048,snake}.spec.ts`

## 1. 目的

既存の 5 ゲームにない「じっくり考えるパズル（2048）」と「定番の反射系（スネーク）」を足す。どちらもスマホではスワイプで遊べるようにする。

## 2. スワイプ（`src/engine/swipe.ts`）

- `swipeDirection(dx, dy, min = 24)`: 移動量の大きい軸で上下左右を決める。24 px 未満は `null`、縦横同量なら横。
- `onSwipe(input, cb, onDown?)`: `input.onPointer` を使い、押してから `min` 以上動いた時点で 1 回だけ `cb` を呼ぶ（指を離すのを待たない。スネークで素早く曲がれるように）。`onDown` が `false` を返した操作は無視する。
- エンジンの `pointerdown` は onPointer → onStart の順に呼ぶ。終局中のスワイプは `onDown` で無視し、onStart のリトライだけを効かせる（リトライ直後の盤面を動かさない）。
- `.stage` は既に `touch-action: none` なので、ステージ上のスワイプでページはスクロールしない。

## 3. 2048（slug `2048`、order 6）

| 項目 | 決定 |
|---|---|
| 盤面 | 4×4、canvas 410×410 |
| 新しいタイル | 動いたときだけ空きマスに 1 枚。2（90%）か 4（10%） |
| 合体 | 1 回の移動で 1 枚につき 1 度だけ。進む向きの先頭側から |
| スコア | 合体でできた数の合計 |
| 2048 到達 | 「2048 達成！」を 2 秒表示して続行（終了しない） |
| 終了 | 空きも隣接する同じ数もなくなったら `submitScore` |
| `game_start` | 最初にタイルが動いたとき（盤面は最初から表示し、開始操作は不要） |
| 操作 | 方向キー／WASD・◀▲▼▶ ボタン（押した瞬間だけ）・スワイプ。終了後は Enter／タップでリトライ |

## 4. スネーク（slug `snake`、order 7）

| 項目 | 決定 |
|---|---|
| 盤面 | 20×20、1 マス 20 px（canvas 400×400）。壁は通り抜けない |
| 初期 | 長さ 3、中央から右向き |
| 速さ | `max(0.06, 0.15 − 食べた数 × 0.004)` 秒／マス |
| スコア | 餌 1 個 10 点 |
| 方向入力 | 2 手まで先行入力。最後に予定している向きと同じ・真逆は捨てる |
| 衝突 | 壁・自分の体。餌を食べない手では今の尾のマスへ進める |
| 終了 | 衝突、または盤面が体で埋まったとき `submitScore` |
| 操作 | Enter／タップで開始・リトライ。方向キー／WASD・◀▲▼▶ ボタン・スワイプで曲がる |

## 5. テスト

- 単体: `swipe.test.ts`、`2048/logic.test.ts`、`snake/logic.test.ts`（乱数は引数で差し替え）。
- E2E: 2048 は `Math.random` を固定（`addInitScript`）し、← ↑ → ↓ の繰り返しで必ず詰む手順（約 150 手）で `game_over` を検証。スネークは放置で右の壁に当たる `game_over` と、曲がって生き延びることを検証。
