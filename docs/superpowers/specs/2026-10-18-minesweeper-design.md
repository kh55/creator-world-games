# マインスイーパー 設計書

- 日付: 2026-10-18
- 対象: `kh55/creator-world-games`（https://browser-games.creator-world.net）
- 追加先: `src/games/minesweeper/`、`tests/e2e/games/minesweeper.spec.ts`

## 1. 目的

2048 に続く「じっくり考えるパズル」として、数字のヒントから地雷の位置を推理するマインスイーパーを足す。スマホでは右クリックがないので、長押しと「旗モード」で旗を立てられるようにする。

## 2. ルールと決定事項（slug `minesweeper`、order 8）

| 項目 | 決定 |
|---|---|
| 盤面 | 10×10・地雷 15 個（初級 9×9/10 と中級 16×16/40 の間の密度）。スマホで 1 マス約 36 px 以上 |
| 盤面の部品 | リバーシと同じく `<button>` のグリッド（Tab で移動でき、読み上げにも対応） |
| 最初の 1 手 | 地雷は最初に開いたときに配置する。開いたマスとその周囲 8 マスには置かない（必ず空白が広がる） |
| 開く | 周りに地雷がない（0 の）マスは、つながった 0 のマスとその縁の数字まで一度に開く |
| 旗 | 隠れたマスに立てる・外す。旗のマスは開けない。残り地雷数 = 地雷数 − 旗の数（負にもなる） |
| まとめて開く | 開いた数字のマスを押すと、周りの旗の数が数字と同じなら残りの隠れたマスをまとめて開く |
| クリア | 地雷以外のマスをすべて開いたら。地雷に自動で旗を立てる |
| 失敗 | 地雷を開いたら。全地雷を表示し、踏んだ地雷と間違った旗を示す |
| タイム | 最初に開いた瞬間から `api.loop` の `dt` で数える（タブが非表示の間は止まる） |
| スコア | クリア時 `max(1, 1000 − 経過秒（切り捨て）)`、失敗は 0。プレイ中の SCORE は 0 |
| `game_start` | 最初にマスを開いたとき（旗を立てただけでは送らない） |
| `game_over` | クリアか失敗のときに 1 回 `submitScore` |

## 3. 操作

| 操作 | キーボード | タッチ／マウス |
|---|---|---|
| 開く | `Tab`・方向キーでマスを移動し `Enter` / `Space` | タップ／クリック |
| 旗 | `F` | 長押し（0.4 秒）／右クリック／「旗モード」を ON にしてタップ |
| 次のゲーム（終了後） | `Enter` | 「もう一度」ボタン、または盤面をタップ |

- 長押しはマウス以外のポインタだけ。Android で長押し後に出る `contextmenu` は既定動作を止めるだけで、旗はマウスの右クリックでだけ切り替える（二重に切り替えない）。
- 長押しで旗を立てた後の `click` は捨てる。終了中に押し始めたタップは「次のゲーム」だけにしてマスは開かない（リバーシと同じ）。
- マスの `keydown`（Enter / Space / 方向キー / F）はマスで処理して `window` へ伝えない（最後の一手の Enter がそのままリトライにならないように）。キーリピートは無視する（方向キーの移動を除く）。

## 4. ファイル構成

- `logic.ts`: `createField`・`placeMines(field, count, safe, rand)`・`openCell`・`chord`・`toggleFlag`・`isCleared`・`flagsLeft`・`scoreFor`・`neighbors`・`cellName`。DOM を使わない。
- `logic.test.ts`: 上記の単体テスト（乱数は差し替え）。
- `game.ts`: 盤面の描画・入力・状態遷移（`ready` → `playing` → `won` / `lost`）。
- E2E: 100 マスの表示、最初の 1 手で `game_start` と空白の広がり、旗、乱数を固定してのクリア・失敗と `game_over` 1 回、終了後タップのリトライ。
